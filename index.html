내 PC로 되나요

최소 사양이면 프로그램은 그대로 돌아갑니다. 대신 자막이 없는 유튜브 영상을 쓸 수 없습니다. 오른쪽 끝은 최소 사양만 넘겼을 때 그 항목이 어떻게 되는지입니다.

그래픽카드없어도 됩니다 NVIDIA · 카드 메모리 8GB영상 만드는 시간이 늘어납니다

「12코어」는 작업 관리자(Ctrl+Shift+Esc) → 성능 탭에 논리 프로세서로 나오는 숫자입니다. 요즘 CPU는 코어 하나가 두 몫을 해서 6코어 CPU가 보통 12로 나옵니다.

설치와 업데이트

  1. 받은 설치기(.exe)를 실행합니다.
  2. 아직 코드서명 전이라 「Windows의 PC 보호」 경고가 뜰 수 있습니다 — 추가 정보 → 실행을 누르면 설치가 이어집니다.
  3. 설치가 끝나면 바탕화면 아이콘으로 실행합니다.
  4. 처음 실행할 때 필요한 도구를 자동으로 내려받습니다. 인터넷 연결이 필요합니다.
  5. 가입 후 관리자 승인을 받아야 사용할 수 있습니다.

자동 업데이트는 아직 없습니다. 새 판이 나오면 이 페이지에서 설치기를 다시 받아 기존 설치 위에 그대로 실행하세요. 먼저 지우지 않으셔도 되고, 설정과 작업물은 남습니다.
